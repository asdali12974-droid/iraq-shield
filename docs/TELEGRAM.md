# جمع قنوات Telegram العامة (P1.3)

يجمع **درع العراق** المنشورات من **قنوات Telegram العامة** التي يحدّدها مدير
المنصّة فقط، عبر **الصفحة العامة** التي يوفّرها Telegram على:

```
https://t.me/s/<username>
```

هذه الصفحة هي **معاينة ويب رسمية** يخدمها Telegram لأيّ قناة عامّة — لا تتطلّب
أيّ مصادقة أو API أو حساب مستخدم. المنصّة لا تستخدم:
- Telegram API / MTProto / Telethon
- api_id / api_hash / session_string
- حساب مستخدم أو بوت
- خدمات كشط أو وسطاء خارجيين

---

## 1) كيف يعمل الجمع

يستخدم المُجمِّع (`TelegramWebCollector`) نفس بنية **Web Collector** الموجودة
في P1.2، بما فيها:
- **الجلب الآمن (SSRF-safe fetcher)** مع تثبيت IP وحدود الحجم والمهلة
- **الأرشيف الإلحاقي** (append-only raw archive) مع حماية الحذف
- **إزالة التكرار** عبر `external_id` + `content_hash`
- **التسخين** (versioning) عند تغيّر المحتوى
- **صحّة المصدر** (health tracking) مع عدّادات النجاح/الفشل
- **RBAC + التدقيق** على كل العمليات

### ما يُستخرَج من الصفحة العامة

| الحقل | المصدر | ملاحظة |
|---|---|---|
| `post_id` | `data-post` attribute | رقم المنشور — يُستخرَج فقط إذا كان متاحاً فعلياً |
| `url` | يُبنى من `t.me/<user>/<id>` | رابط المنشور العام |
| `text` | `.tgme_widget_message_text` | نصّ المنشور |
| `published_at` | `<time datetime>` | الطابع الزمني — `None` إذا غاب |
| `views` | `.tgme_widget_message_views` | عدد المشاهدات كنصّ |
| `media_meta` | عناصر الوسائط المرئية | النوع (صورة/فيديو/ملف/استطلاع) + بيانات وصفية |
| `forwarded_from` | `.tgme_widget_message_forwarded_from_name` | اسم المصدر الأصلي |
| `collected_at` | وقت الجمع | طابع زمني من المنصّة |
| `content_hash` | SHA-256 للنصّ المُعيَّر | لإزالة التكرار |

### قيود صريحة (مذكورة بأمانة)

- صفحة `t.me/s/` تعرض **نافذة محدودة** من المنشورات الأخيرة فقط — لا ندّعي
  الحصول على التاريخ الكامل للقناة.
- `post_id` يُستخرَج من `data-post` في HTML — إذا لم يكن متاحاً لا ندّعي وجوده.
- `published_at` يأتي من `<time datetime>` — إذا غاب يكون `None`.
- الجمع **تدريجي** (incremental) قدر الإمكان: يُحفَظ أعلى `post_id` كـ `last_cursor`
  وتُتجاوَز المنشورات المُجمَّعة مسبقاً.

## 2) تسجيل القنوات والتحقّق منها

المدير يزوّد قائمة القنوات (username + التصنيف التحريري). لزرع القائمة الأوّلية:

```bash
cd apps/api && source .venv/bin/activate
python -m scripts.seed_telegram_sources
```

كلّ قناة تُسجَّل: **معطّلة** (`enabled=false`)، **بانتظار التحقّق**
(`verification_status=pending`)، وبموثوقية `C` كقيمة محايدة.

**التحقّق** (عبر HTTP — لا Telegram API):

```
POST /api/v1/sources/{id}/verify        # يتطلّب sources:manage — ويُدقَّق
```

- يجلب صفحة `https://t.me/s/<username>` عبر HTTP
- يتحقّق من وجود محتوى قناة حقيقي في الصفحة
- يستخرج عنوان القناة وعدد المنشورات المرئية
- يُحدِّث `verification_status` إلى `verified` فقط عند نجاح حقيقي
- لا يُدَّعى التحقّق إذا فشل الجلب أو كانت الصفحة فارغة

---

## 3) ما الذي يُجمَع ويُؤرشَف

لكلّ منشور عام: الرابط، معرّف المنشور (إن توفّر)، وقت النشر (إن توفّر)، النصّ،
**وصف** الوسائط (النوع + بيانات وصفية مرئية — دون تنزيل الملفّات)، بصمة المحتوى،
والتمثيل الخام (JSON). الأرشيف **إلحاقي** ومحميّ من الحذف؛ أيّ تعديل يُنشئ
**نسخة جديدة** دون حذف القديمة.

- **إزالة التكرار:** `username:post_id` + `content_hash`.
- **المحتوى المُعاد توجيهه:** تُحفَظ بيانات المصدر الأصلي (الاسم والرابط).
- **الموثوقية** منفصلة تماماً عن التصنيف التحريري وعن التحقّق.

## 4) مسارات الـ API

| الطريقة | المسار | الصلاحية |
|---|---|---|
| POST | `/api/v1/sources` (`source_type=TELEGRAM_PUBLIC_WEB`) | `sources:manage` |
| POST | `/api/v1/sources/{id}/verify` | `sources:manage` |
| POST | `/api/v1/sources/{id}/collect` | `collection:run` |
| GET | `/api/v1/archive/{id}/relations` | `archive:read` |

## 5) الاختبار

منطق المُجمِّع بالكامل قابل للاختبار **دون اتصال بـ Telegram** عبر خادم HTTP
محلي (`FeedServer`) يخدم صفحات HTML بنفس بنية `t.me/s/`. الاختبارات تغطّي:
الاستخراج، الجمع الأوّلي والتدريجي، إزالة التكرار، التسخين، المنشورات المُعاد
توجيهها، الوسائط، الأخطاء، SSRF، وصحّة المصدر.

## ملحق: MTProto/Telethon (مؤجَّل — adapter مستقبلي)

الكود المُبقَى في `app/modules/collection/telegram/` (port.py، fake.py،
telethon_adapter.py، client.py، collector.py) هو **adapter مستقبلي** لبروتوكول
MTProto عبر Telethon. هذا الكود **غير مستخدم** في مسار التشغيل الحالي
(`TELEGRAM_PUBLIC_WEB`) ولا يتطلّب أيّ اعتمادات. يمكن تفعيله لاحقاً إذا دعت
الحاجة إلى جمع أعمق (تاريخ كامل، رسائل أقدم).
